# G4_ProjetoJogo

Repositório da **Entrega 01** do Grupo 04 da disciplina **FGA0208, Arquitetura e Desenho de Software**, Turma 01, ministrada pela professora Milene Serrano na Universidade de Brasília durante o semestre 2026.2.

**[Acessar a documentação publicada](https://unbarqdsw2026-2-turma01.github.io/2026.2-T01-_G4_ProjetoJogo_Entrega_01/)** | [Visão do projeto](docs/Projeto/Projeto.md) | [Atas de reunião](docs/Atas/Gerais.md) | [Participações](docs/Base/1.2.ParticipacoesBase.md) | [Site da disciplina](https://sites.google.com/view/unb-fcte-arqdsw)

## Sobre o projeto

O **G4_ProjetoJogo** é um RPG medieval 2D de mundo semiaberto, com história linear e combate por turnos. Sua mecânica distintiva é a combinação de elementos químicos coletados durante a exploração para criar itens, cujas receitas são registradas no Livro do Aventureiro.

O projeto enfatiza a jogabilidade, a usabilidade e a experiência do usuário. A Entrega 01 documenta a concepção inicial e os estudos do Módulo Base por meio de:

- artefatos generalistas, como Rich Pictures e Mapa Mental;
- modelagem de requisitos não funcionais com o NFR Framework;
- engenharia reversa de funcionalidades de jogos de referência;
- modelagem de processos com BPMN;
- análises sobre o uso de inteligência artificial generativa;
- atas, históricos de versão e registros de participação que preservam a rastreabilidade do trabalho.

## Documentação local

A documentação é publicada com [Docsify](https://docsify.js.org/) a partir da pasta `docs/`. Para executá-la localmente, é necessário ter o Node.js e o npm instalados.

```bash
git clone https://github.com/UnBArqDsw2026-2-Turma01/2026.2-T01-_G4_ProjetoJogo_Entrega_01.git
cd 2026.2-T01-_G4_ProjetoJogo_Entrega_01
npm install
npx docsify-cli serve docs
```

Depois, acesse `http://localhost:3000`. A configuração publicada usa a branch `main` e a pasta `/docs` como origem do GitHub Pages.
