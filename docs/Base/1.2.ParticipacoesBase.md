# 1.2. Participações (Base)

## Descrição

Esta página consolida as participações e contribuições de cada membro do Grupo 04 na entrega. O **Quadro Geral** reúne todos os integrantes com o rastro dos seus commits, e as seções por subequipe detalham a contribuição de cada um dentro do seu relatório.

## Objetivo

Evidenciar, de forma rastreável, o que cada integrante produziu na entrega, ligando a contribuição declarada aos comprobatórios no repositório.

## Metodologia

Cada linha do quadro registra o membro, sua subequipe, o que produziu, a significância da contribuição e os comprobatórios. A coluna **Commits** aponta para o histórico filtrado por autor no GitHub, permitindo verificar diretamente o que foi versionado por cada pessoa.

> **Como preencher sua linha:** descreva suas contribuições na coluna *Contribuição*, e confirme se o link de commits aponta para o seu usuário do GitHub. Para os membros ainda sem commits registrados, substitua `<usuario-github>` pelo seu login no formato `https://github.com/UnBArqDsw2026-2-Turma01/2026.2-T01-_G4_ProjetoJogo_Entrega_01/commits?author=SEU_USUARIO`.
