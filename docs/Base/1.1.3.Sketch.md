# Sketch

### Introdução

A fase de *Sketch* é dedicada à geração individual de soluções criativas para o problema central do projeto. Cada participante desenvolve diversos esboços explorando diferentes abordagens, focando na variedade de ideias sem se preocupar com viabilidade técnica ou refinamento estético.

Ao final, a equipe compartilha e debate as propostas para selecionar as mais promissoras. Essa abordagem ágil e colaborativa estimula a inovação e evita a paralisia por análise, garantindo um fluxo constante de novas possibilidades.
