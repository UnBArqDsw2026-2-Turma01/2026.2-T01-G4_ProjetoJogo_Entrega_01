# Prototype

### Introdução

A fase de *Prototype* transforma as ideias selecionadas em modelos tangíveis para validar a experiência do usuário. O foco está na velocidade e na eficiência, criando representações fiéis o suficiente para simular a usabilidade real sem a necessidade de um desenvolvimento técnico completo.

Trabalhando de forma colaborativa, a equipe materializa a solução usando recursos e ferramentas ágeis. Esse protótipo funcional serve para testar as hipóteses na etapa seguinte com usuários reais, permitindo coletar *feedbacks* valiosos e identificar ajustes necessários antes da implementação final.
