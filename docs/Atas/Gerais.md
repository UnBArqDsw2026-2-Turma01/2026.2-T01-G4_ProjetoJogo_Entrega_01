# Atas — Reuniões Gerais

## Descrição

Registros oficiais das reuniões que envolvem **todos os integrantes** do Grupo 04. São as reuniões de alinhamento geral, nas quais se define o rumo do projeto, a distribuição de trabalho entre os subgrupos e as decisões que afetam a equipe inteira.

## Objetivo

Manter o histórico das reuniões gerais do grupo, evidenciando as decisões que impactam todos os subgrupos.

## Metodologia

Toda reunião é registrada em uma ata própria, seguindo o modelo definido em [Ata Padrão](/Guias/AtaPadrao.md), baseado no padrão do MCTIC. Cada ata identifica data, local, participantes, pauta, assuntos tratados e compromissos, com responsável e prazo.

> **Como registrar uma nova reunião:** copie o modelo da [Ata Padrão](/Guias/AtaPadrao.md), salve como `docs/Atas/AtaGeralXX.md`, preencha os campos e adicione a linha correspondente na tabela de registro abaixo.
